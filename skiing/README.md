# 滑雪大冒险 Skiing Adventure

3D 雪山无尽滑雪游戏:第三人称追尾视角,躲树木岩石、穿回转旗门、吃星星加速,滑得越远分越高。
Three.js (r158, 已本地化到 lib/) + 原生 JavaScript 实现,零构建,打开即玩。

## 在线试玩

https://games.leonova.xyz/skiing/

## 本地运行

无需安装任何东西,直接用浏览器打开 `index.html` 即可。
也可以起一个本地服务器:

```bash
npx serve .
```

## 操作方式

### 电脑(键盘)

| 按键 | 功能 |
| --- | --- |
| ← → / A D | 转向 |
| ↑ / W | 加速 |
| ↓ / S | 刹车 |
| P | 暂停 / 继续 |
| Enter | 开始 / 重新开始 |

### 平板 / 手机(触屏)

- **按住游戏画面左右拖动**:转向(左右偏移越大转向越急)
- 右上角 **II** 按钮:暂停
- 标题 / 结束界面:轻点游戏画面即开始

## 玩法说明

- 无尽下坡自动滑行,**滑行距离(米)是主要得分**,最高分保存在浏览器本地。
- 撞上松树 / 岩石损失一条命(共 3 条),重生带 2 秒无敌闪烁;全灭游戏结束。
- 从回转旗门两杆之间穿过 +50 分,漏过无惩罚。
- 星星 +100 分;橙色加速带短暂提速。
- 滑过蓝色**跳台**起跳腾空,空中可飞越树木岩石,落地按飞行距离加分。
- 巡航速度随里程从 36 km/h 提升到 122 km/h,障碍越刷越密。

## 技术要点

- Three.js r158 UMD 构建本地化(`lib/three.min.js`),普通 script 标签引入,不依赖 CDN。
- 逻辑与渲染分离:`js/logic.js` 纯 JS 零环境依赖(Node 可直接跑),`js/scene.js` 只负责把逻辑状态同步成 THREE mesh。
- 程序化生成的雪山场景:fBm 值噪声高度场(自然起伏,非规则波形)、蜿蜒谷壁 + 弯道侧倾(视线随雪道走向摆动)、向前下坡、滑道道内/道外双色着色 + 橙蓝边界标志杆、圆锥松树、多面体岩石、积木滑雪小人、飘雪粒子,无任何外部素材。
- 跳台:逻辑层抛物线腾空(车速越快跳得越高),空中免撞可飞越障碍,落地按飞行距离加分。
- WebAudio 合成音效:随速度变化的滑行风声、过门叮声、拾取与撞击声。
- `?demo=秒数` 自动演示快进(AI 躲障碍、阵亡自动重开)、`?touch=1` 强制显示触屏控制,用于预览截图与调试。

## 文件结构

```
index.html        入口页面(WebGL 容器 + DOM HUD + 覆盖层)
style.css         页面样式 + 触屏控制区
lib/three.min.js  Three.js r158 (UMD, 本地化)
js/config.js      常量(雪道几何/速度/命数/得分/跳台)与难度曲线
js/logic.js       纯逻辑:玩家(含跳台腾空) / 障碍 / 旗门 / 道具 / 跳台 / 碰撞 / 计分
js/audio.js       WebAudio 音效与滑行风声
js/scene.js       THREE 场景:雪山 / 松树 / 旗门 / 滑雪小人 / 相机 / 飘雪
js/game.js        游戏状态机、事件到音效、HUD、最高分
js/main.js        键盘 + 触屏拖动输入、demo 快进与主循环
test/simulate.js  Node 无头冒烟测试: node test/simulate.js
```
